## Installation
1. Install [MelonLoader](https://melonwiki.xyz/) (v0.4.3 required).
2. Download the latest `ToFMultiplayer.dll` from the [Releases](#) page.
3. Place the file into your `Mods` folder:
   `...\SteamLibrary\steamapps\common\The Thrill of the Fight\Mods`
3. Download [Steamworks](https://github.com/rlabrecque/Steamworks.NET/releases/tag/20.1.0) and place `Steamworks.NET.DLL` and `steam_api64.dll` in:
   `The Thrill of the Fight\game_Data\Managed`
5. Launch the game via Steam.

## How to Use
1. **Open Menu:** Press **F4** on your keyboard once the game is loaded [cite: 1].
2. **Hosting:**
   - Click **Host PUBLIC** to be visible in the lobby browser [cite: 1, 5].
   - Click **Host PRIVATE** and share the 6-digit code with a friend [cite: 1, 2].
3. **Joining:**
   - Click **Browse PUBLIC Lobbies** to see active hosts [cite: 1, 5].
   - Enter a code in the text field and click **Join** for private matches [cite: 1, 2].
